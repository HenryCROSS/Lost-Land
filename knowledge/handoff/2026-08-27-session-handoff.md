## 二、本会话落地了什么（`98fdafe..5b1fc8e`）

### 世界变活了

- **文化系统**（`4aec07e`）：`CultureKind`/`CultureAttrs`/`CultureTable` 三件套（**注意没有叫 `CultureDef` 的类型**）。文化在据点建立时按「资源 + 地形 + 邻近据点 + 随机」选出，文化权重函数**一个字节种族数据都不读**。
- **敌对与战争**：本体新增 `lostland:goblin` 种族。编年史真的能打出「矮人矿城被哥布林部落攻灭」，且那座城在地上是石头废墟、**零扇门**。
- **占领结局**（`3f7ce2b`）：同族 75% 倾向占领、异族 12.5%。存活据点回到文化落地前的水位（233/231/242 对比落地前 235/238/243）。战争仍多 78%，但世界不再被打空。
- **世界生成参数**（`d93d61a`）：`sea_level`/`mountain_level`/`octaves` 三个旧旋钮此前**零生产调用者**，现已接进新游戏流程并进存档。新增第四个旋钮 `continent_shrink`——**现有三个参数表达不了群岛**（实测：世界放大四倍，水域/山地/陆块数/最大陆块四项逐位相同），新旋钮把「碎」与「淹」拆成两个正交维度。四档预设：大陆/群岛/山地/内陆，入口在 `config.json5` 的 `new_game` 段。

### 玩家第一次真的能玩

- **输入接线**（`8f8d1a9`）：意图产出者从 3/24 涨到 11/24。空格交互、I 背包、C 制作、EUXPG 六个物品键。家具有了「放置状态」（`GroundItemStack::placed`），放置的家具独占该格，未放置的就是普通物品。
- **交互列表规则**（所有者裁定）：按空格扫描脚下 + 相邻八格（八向，与移动一致）。0 格有东西 → 提示；1 格 → 直接开那格的**交互列表**；2 格以上 → 先弹**方向列表**再进交互列表。**交互列表无条件弹，一件也弹。**
- **配置合并**（`1881fa9`）：`load_or_default` 此前整份替换默认表，导致**新增/改动的默认键位对已有玩家永久不可达**。现改为合并。新增 `GameConfig::unbound_actions` 区分「刻意解绑」与「文件版本旧」。

### 屏幕上第一次看得见

- **地面物品/NPC/家具接进渲染**（`41d0dfe`）：此前 `render_surface` 只画地形和玩家。地面物品统一一个「团」（所有者裁定）。
- **九张建筑地形贴图**（`0bcb341`）：木墙/石墙/木地板/石地板/开门/关门/窗/上下楼梯。
- **HUD 五张 UI 贴图的静默缺陷**（同上）：`skin.rs` 查的是**裸名字** `"ui_daynight_bar"`，而运行期图集条目名是 `"lostland:ui_daynight_bar"`。五张 UI 贴图全部查不到、每帧静默退回纯色皮肤、**不打任何日志**（`uv_rect` 返回 `None` 是设计上的正常降级路径）。已修。
- **NPC 分层出图**（`dad9583`）：身子查种族 ID、挂件查职业 ID，资产量从 `种族 × 职业`（52→117）降到 `种族 + 职业`（17）。示例 mod 的 `examplemod:half_elf`/`examplemod:necromancer` 是活证据——`crates/` 下零提及，照样有自己的样子。

### 一个让游戏当场不可玩的缺陷（`8d1882f`）

**根因**：一个平民站在常驻区块边界上，行为树掷出往边界外走，目的地区块未常驻 → `resolve_move` 返回空效果 → **没有 `ScheduleNext`，`next_action_at` 一个 tick 不动** → 原样排回时间轴、同一刻再弹出 → 决策的三个输入（世界状态、`DetRng::for_entity`、树）一个都没变 → **确定性系统里的硬死循环**。玩家永远排在它后面。

**修法**：`TurnEngine::perform` 新增 `guarantee_progress`——非受控实体结算为空时补跑一次 `Intent::Wait`。**玩家那条路刻意不走**（玩家不存在死循环，下一轮输入不是世界状态的函数）。`MAX_STEPS_PER_ADVANCE` 一个字没调；它的文档原本声称能防住这类缺陷，**已被实机证伪并改写**。

**顺带核实出的重要事实**：
- **非敌对实体此前并不互相挡路**——`resolve_move` 里一行占位检查都没有，NPC 直接摞在同一格。`place_roster` 和 `route_move_to_attack` 两处注释写着「每格至多站一个单位」，**在本批之前都不成立**。
- `Agent::affiliations` **至今没有任何生产者**，两条构造路径都写死空列表。而 `is_hostile` 的兜底是「自己没有势力归属 → 对谁都敌对」，于是它对**每一对**实体返回 `true`。新增 `declared_hostile`（双方都无归属时不敌对）绕开这个退化。

## 四、等所有者裁定的问题（按拖着的代价排序）

### 会越拖越贵

1. **`Agent::affiliations` 什么时候接生产者？** 在它接上之前，`declared_hostile` 在本体里恒为「不敌对」，「敌对就攻击」那一支在真实游戏里跑不到。最自然的接法是物化 NPC 时挂一条据点势力（`SettlementSite::id` 现成）。**会动世界摘要。**
2. **`Owner`（物品归属）认领还是正式放弃。** P6 拒绝时列的三个缺席场景今天只剩「商店」一个（卫兵盘查与 FOV 目击判定都已落地，完整设计已写完 `ownership-and-crime-detection.md`）。加字段就必须同批改 `can_merge`，**每多一条物品产出路径就更贵**。
3. **行为树要不要数据化**（P8 前置）。所有者已裁定不做第三方 Rust 扩展，但指令系统与据点派工天然需要「行为随数据变化」，否则树的数量按「工种 × 状态」爆炸。**别在不裁定的情况下让实现悄悄选了最省的那条。**

### 设计口径

4. **战争频率**：文化让战争多了 78%（25/18/15 → 35/43/25 场）。占领落地后据点损失从 −5% 收窄到 −1%。**缺一个「多少算太多」的口径。** 要收就调 `WAR_DENOMINATOR`（开战基础概率分母，现 8）或 `WAR_RANGE_IN_SPACINGS`（能打多远，现 3）。
5. **占领之后 NPC 名册的种族跟着重抽，对吗？** 一座 human 渔港被 human 农庄占领后，名册按农庄权重表重抽，**有小概率抽到矮人**——「同族占领」之后主体人口反而换了族。可读作「殖民换血」，也可以认为占领只该换统治者。
6. **同文化的两座据点要不要允许互相占领？** 现在允许，实测**这是最常见的一类**。写成「同文化不开战」会明显压低战争总场次，**直接改变第 4 条的口径**。
7. **文化↔种族权重方向被反转了**：所有者说「建立者种族给权重但不锁死」（种族 → 文化），实现做成了**文化 → 种族**（`CultureAttrs.founder_races`）。理由是反方向要再注入一张「种族↔资源亲和」表、表面积翻倍。**若不同意，改法是加 `RaceDef.settlement_affinity` 注入表，不是推翻已落地结构。**
8. **默认世界预设要不要换？** 现在默认「大陆」= 旧默认，所以基准没因参数变化而动。改成「内陆」（少水）是一次真正的行为变更，**两条基准都要再重冻**。
9. **渔夫问题只解决了一半**：形态参数管到了「水有多少」，但 `mods/lostland/resources.json5` 里淡水丰度 300‰ 是七种资源里最高的。**要不要连丰度一起调？**（注：加入鱼人/蜥蜴人后这可能不再是问题。）

    「每天都会有在据点附近巡逻的任务」。** 这个问题的正解不在移动结算层，而在行为层

## 六、怎么跑起来看

```bash
cargo run --release -p ll-game
```

| 键 | 作用 |
|---|---|
| WASD / 方向键 | 移动（八向），撞到敌对目标即攻击 |
| 空格 | 交互（脚下 + 相邻八格） |
| I | 背包（选中后 E 装备/卸下、U 使用、X 丢弃、P 放置） |
| C | 制作菜单 |
| G | 捡起 |

按键可在 `config.json5` 的 `bindings` 段改；世界生成预设在同一文件的 `new_game` 段（**只在建新档时生效**，老存档带着建档时那组参数）。

**能走通的一条完整链**：装上铁匠锤 → C 开制作 → 砌一座锻炉（6 铁锭）→ I 里选中炉子 → P 放下 → 空格交互 → 选配方 → 打出一把铁短剑。

**注意**：菜单键和截图键按了没反应，见第四节第 16、17 条。NPC 至今没有名字（`Agent` 连 `name` 字段都没有，`CultureAttrs` 的 `naming` 字段未落地）。
