## 一、纪律：在原有六条之上新增两条

7. **门禁检查与 `git push` 绝不写在同一条 `&&` 链里。** 本会话踩过：
   `grep ... && awk ... && git push`，中间的 `awk` 即使没有任何输出也返回 0，
   于是在门禁 `EXIT=101` 的情况下推送了。**根子不在 `awk`，在于「用管道链的
   退出码当闸门」等于把闸门交给链上最后一个命令。** 正确写法是把判据显式取出
   来再比：

   ```bash
   EXITOK=$(grep -c '^EXIT=0$' "$LOG"); FAILED=$(grep -cE 'test result: FAILED' "$LOG")
   OOM=$(grep -c 'LNK1102' "$LOG")
   if [ "$EXITOK" = "1" ] && [ "$FAILED" = "0" ] && [ "$OOM" = "0" ]; then git push ...; fi
   ```

   同一个陷阱另一个会话在 `run_acceptance_demos.sh` 里也差点踩到（`echo | while read`
   把循环体放进管道子 shell，cargo 的退出码传不出来），它改成了 `for` 循环。

8. **本地门禁在高并行下会因链接器内存不足而假失败。** 症状：`EXIT=101`，日志里
   `LINK : fatal error LNK1102: 内存不足`，且**一条测试都没跑到**（`test result`
   行为零）。原因是 `ll-game` 的测试二进制要链 257 个 object file 加一百多个
   rlib，两三个 cargo 并发就能把 MSVC 链接器挤爆。

   **这不是代码缺陷，重跑就绿。** 把它当真失败去「修」会浪费一整轮。并行批次
   建议不超过两个，且门禁跑的时候不要另外派活。

### 一个让游戏当场崩溃的缺陷（`9e7cb89`）

**根因**：常驻区块集合**只围着玩家维护**（`STREAM_RADIUS_ZONES = 2`），上限
256 个区块，超了就驱逐；而 `advance_ai` **零常驻过滤**，时间轴弹出谁就结算谁。
玩家一路走过去物化了多座据点的 NPC，它们永远留在 `world.actors`；玩家继续走，
那些 NPC 脚下的区块被驱逐，但它们照样跑行为树，卫兵一算 FOV →
`SurfaceWindow::terrain_at` 查不到地形 → **panic，游戏当场退出**。

**修法**：`ll_world::sight_residency::fov_neighborhood_resident` —— 算 FOV 之前
先确认观察者视野半径覆盖的每个区块都常驻，不满足就返回 `None`（看不见就是看
不见，ADR 0015）。**没有把 `SurfaceWindow` 的 panic 改哑**——那个 panic 是刻意
的，改哑等于把纪律永久拆掉。

**同一套判据也加在 `apply.rs` 那处 FOV 上**（核实结论是生产路径不可达，但
`apply` 是全局唯一写入口 C1，在那儿 panic 一样崩）。

**遗留的更大问题**：离屏 NPC 仍在**以全保真度被模拟**——远在天边的卫兵每回合
都在跑完整 FOV。规格 §9 的三档 LOD 就是为这件事设计的，属 P9。本会话只止血。

### 滚动文件日志（`039edce`）

`logs/lostland.<日期>.log`，按天滚动、保留 7 天，stdout 与文件双层共用同一个
`EnvFilter`，文件层 `.with_ansi(false)`。**刻意不用 `tracing_appender::non_blocking`**
——那要返回 `WorkerGuard`，守卫被 drop 后日志静默停写（本仓库最恨的失败模式），
且要改 7 个调用点的签名。用阻塞式 appender：签名不变、无守卫陷阱，代价是写入
阻塞（info 级日志一局几十行，可忽略）。

`.gitignore` 写的是 `logs/` 而**不是** `/logs`：日志目录建在**进程 cwd** 下，
而 `cargo test` 给每个 crate 各自的 cwd，只锚根目录会把 `crates/*/logs` 漏进
版本库。

### 文化归属与敌对判定（`2a86a29` + `bee87eb`）

前一份交接的**裁定 1**（种族默认敌对）的最终形态。**没有给 `RaceDef` 加字段**

- **`lostland:cultureless`**（无文化）是**只 intern、不 define** 的文化索引

- **判据是对称的**（所有者裁定：「只要有一方处于敌对状态，另一方也会发起攻击」）：

## 七、怎么跑起来看

```bash
cargo run --release -p ll-game
```

日志现在同时落到 `logs/lostland.<日期>.log`（按天滚动、保留 7 天）——**遇到崩溃
把那个文件捞出来即可**，不用靠终端回滚。

| 键 | 作用 |
|---|---|
| WASD / 方向键 | 移动（八向），撞到敌对目标即攻击 |
| **Esc** | **逐层往回退**：开着子菜单就关它，什么都没开就开菜单（继续/设置/退出） |
| 空格 | 交互（脚下 + 相邻八格），窗口居中；现在也能开关门 |
| I / C / G | 背包 / 制作 / 捡起 |
| M | 世界地图（四档缩放、玩家橙色标记、据点标记） |
| F2 | 截图（存到数据目录的 `screenshots/`，按帧号编名，绝不覆盖） |
