## 地表内容：`surface_preview.png`

`surface_preview.png` 由

```
# ~~cargo run -p ll-game --example surface_preview~~   # 2026-08-29 起该 target 已删
# 【2026-08-31 批次 27 起改成这一条，见本文顶部横幅】

# 有意更新这张基准（先判断是不是有意的视觉调整，见下方处置规矩）：
LL_BLESS_VISUAL=1 cargo test -p ll-game --test visual_baselines 地表内容预览与基准逐像素一致
```

生成（无需 GPU、无需窗口）。图里应当能一眼看见五样东西：

- **琥珀色的堆**：地面物品堆的「团」。图中两处——一处那一格上躺着三样
  不同的东西，另一处只躺着一样，**两处画出来完全一样**。这是项目所有者
  的裁定：「无论是一个还是N个……统一用一个团表示哪一个地方有东西」。
- **带火口的锻炉**：`lostland:forge` 自带的那张贴图（`assets/sprites/forge.png`）。
- **紫罗兰的箱体**：通用放置家具记号——图中那件立着的铁锭没有自带贴图，
  于是退回了这一张。
- **一个矮人铁匠**（上方）：赤褐大胡子、宽肩、橙色的锻工衣、胸口一枚
  橙色的锤、手里一把钢锤——「矮人 × 铁匠」那张合成图。
- **一个人类渔夫**（下方）：小麦肤、褐发、青色的渔夫衣、胸口一枚青色的
  鱼、手里一张撒开的渔网。与上面那个矮人**每一层都不同**，一眼分得出
  不是同一个人。
- **钢蓝色的人形**：玩家（`hero_idle_0`，既有资产，未改动）。

这两个 NPC 刻意取了不同的种族与职业：「所有 NPC 长得一模一样」正是
所有者报的现象，这张预览图如果只摆两个同族同职业的人，恰好会把那个
现象重新藏起来。

## 它证明什么，不证明什么

**证明**：什么东西被画在了哪一格、谁挡住谁——位置、层序、图集键的选择
全部来自生产代码（`ll_game::surface_draw`、`ll_render::sprite`、
`ll_render::camera`），`examples/surface_preview.rs` 一行都没有自己重推。

**不证明**：颜色对不对。真实渲染路径会按 `tint` 给每个精灵乘一次颜色
（昼夜/天气/迷雾），这张图恒按原色拷贝。颜色那一侧仍然只有 GPU demo
能验，见 `crates/ll-render/tests/visual/README.md`。

## 比对失败时的处置规矩

与 `crates/ll-render/tests/visual/README.md` 同一条，逐字适用：**绝不
允许「看着不一样就重新跑一遍覆盖」**。先判断是有意的视觉调整还是缺陷，
只有确认是有意调整才更新，并在提交信息里写清改了什么、为什么。
