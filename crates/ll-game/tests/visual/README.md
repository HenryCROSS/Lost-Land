# 地表内容渲染的可视化验收产物

本目录有三张图，各验一件事：

- **`surface_preview.png`**——地表内容（物品堆/家具/NPC/玩家）画在了
  哪一格、谁挡住谁，用真实生成的世界。见下方「五样东西」一节。
- **`settlement_preview.png`**——据点建筑地形（石墙/木墙/石地板/木地板/
  关门/开门/窗/上下楼梯）长什么样、互相分不分得开，用手工摆的一间小屋
  平面图。见「据点建筑地形」一节。
- **`npc_roster_preview.png`**——每一个有图的种族 × 每一个有图的职业
  长什么样、互相分不分得开。见本文件末尾「NPC 点名册」一节。

## 地表内容：`surface_preview.png`

`surface_preview.png` 由

```
cargo run -p ll-game --example surface_preview
```

生成（无需 GPU、无需窗口）。图里应当能一眼看见五样东西：

- **琥珀色的堆**：地面物品堆的「团」。图中两处——一处那一格上躺着三样
  不同的东西，另一处只躺着一样，**两处画出来完全一样**。这是项目所有者
  的裁定：「无论是一个还是N个……统一用一个团表示哪一个地方有东西」。
- **带火口的锻炉**：`lostland:forge` 自带的那张贴图（`assets/sprites/forge.png`）。
- **紫罗兰的箱体**：通用放置家具记号——图中那件立着的铁锭没有自带贴图，
  于是退回了这一张。
- **一个矮人铁匠**（上方）：赤褐大胡子、宽肩、胸口一枚橙色的锤——种族
  身子 + 职业挂件两层叠出来的。
- **一个人类渔夫**（下方）：小麦肤、褐发、胸口一枚青色的鱼。与上面那个
  矮人**两层都不同**，一眼分得出不是同一个人。
- **钢蓝色的人形**：玩家（`hero_idle_0`，既有资产，未改动）。

这两个 NPC 刻意取了不同的种族与职业：「所有 NPC 长得一模一样」正是
所有者报的现象，这张预览图如果只摆两个同族同职业的人，恰好会把那个
现象重新藏起来。

## 它证明什么，不证明什么

**证明**：什么东西被画在了哪一格、谁挡住谁——位置、层序、图集键的选择
全部来自生产代码（`ll_game::surface_draw`、`ll_render::sprite`、
`ll_render::camera`），`examples/surface_preview.rs` 一行都没有自己重推。

**不证明**：颜色对不对。真实渲染路径会按 `tint` 给每个精灵乘一次颜色
（昼夜/天气/迷雾），这张图恒按原色拷贝。颜色那一侧仍然只有 GPU demo
能验，见 `crates/ll-render/tests/visual/README.md`。

## 比对失败时的处置规矩

与 `crates/ll-render/tests/visual/README.md` 同一条，逐字适用：**绝不
允许「看着不一样就重新跑一遍覆盖」**。先判断是有意的视觉调整还是缺陷，
只有确认是有意调整才更新，并在提交信息里写清改了什么、为什么。

## 自动化的那一半

这张图是给人看的。给机器看的那一半在
`crates/ll-game/tests/surface_render.rs`：它用同一份真实 `mods/` +
`assets/`，断言三类内容各自选中了哪个图集键、且那个键在真实图集里对应
一块**有不透明像素**的矩形。两边合起来才是完整证据，见那个文件的模块
文档。

## 据点建筑地形：`settlement_preview.png`

由

```
cargo run -p ll-game --example settlement_preview
```

生成（同样无需 GPU、无需窗口）。图里是一间手工摆好的小屋，一眼应当
看得出九样东西互不相同：

- **深灰错缝砌石**：石墙（外墙一圈）。
- **浅灰错缝铺面**：石地板（左半间）。同为灰色，但墙明显更暗——
  「墙暗地板亮」这条配色规则的落点。
- **暗褐竖向板缝**：木墙（隔断那一列）。
- **暖褐横向板缝**：木地板（右半间）。同为褐色，规则同上。
- **橙褐门板 + 两枚金色把手**：关着的门（下墙偏左）。
- **近黑门洞 + 收到两侧的门板**：开着的门（下墙偏右）。与关着的门差的
  是整格大部分像素，不是一两笔细节。
- **浅青玻璃 + 十字窗棂**：窗（右墙）。
- **暖黄向上三角 + 越往上越亮的阶梯**：上楼梯（左半间）。
- **冷蓝向下三角 + 越往上越暗的阶梯**：下楼梯（右半间）。

### 它证明什么，不证明什么

**证明**：这九种地形在真实图集里都查得到条目、都有图、且互相长得不
一样。每一格该查哪个图集键走的是生产路径上的
`ll_game::layout::terrain_atlas_key`，图集走的是生产路径上的
`ll_game::app::load_sprite_sources` + `ll_render::atlas_pack::pack_atlas`
——手工摆的只有「哪一格是哪种地形」这一件事。

**不证明**：颜色经过昼夜/天气/迷雾 tint 之后还对不对，与
`surface_preview.png` 同一条局限。

**为什么手工摆平面图而不用真实世界**：世界生成不保证玩家出生点附近
一定有据点，靠随机世界去看这九种地形是碰运气。

### 自动化的那一半

`crates/ll-game/tests/atlas_coverage.rs`：逐条断言 `define_base` 注册的
全部 17 种本体地形都查得到图集条目、都铺满整格、两两之间至少四分之一
像素不同，另外覆盖 HUD 皮肤的五张 UI 贴图与玩家动画每一帧。

## NPC 点名册：`npc_roster_preview.png`

由

```
cargo run -p ll-game --example npc_roster_preview
```

生成（同样无需 GPU、无需窗口）。一行是一个种族，一列是一个职业；
**第一列没有职业挂件**，是那个种族的裸身子——把它和同一行右边的格子
对照，就能看清「挂件只改胸口那一块、别的一概不动」。

图里应当看得出：

- **人类**：中等身量、小麦肤、褐发，紫色上衣。
- **矮人**：矮两格、宽两像素、赤褐大胡子。
- **精灵**：最高最窄、近白肤、浅金发、尖耳。
- **哥布林**：最矮、绿皮、黑发、招风大耳。
- **半精灵**（`examplemod:half_elf`）：示例 **mod** 自己声明、自己配图的
  种族。它出现在这张图上，本体的 Rust 一个字都没为它写过——这就是
  「加第 10 个种族只加数据」那条要求的样子。
- 每一列胸口那块 6×6 徽记颜色与图形都不同：剑（战士）、星芒（法师）、
  弓（游侠）、盾（卫兵）、钥匙（管理者）、矛（民兵）、麦（农夫）、
  箭镞（猎户）、剁刀（屠夫）、锤（铁匠）、鱼（渔夫）、牧杖（牧羊人）、
  砖（石匠），外加示例 mod 的死灵法师。

### 它证明什么，不证明什么

**证明**：每一格该查哪两个图集键走的是生产路径上的
`ll_game::surface_draw::npc_draws`；图集走的是生产路径上的
`ll_game::app::load_sprite_sources` + `ll_render::atlas_pack::pack_atlas`；
两层怎么叠、谁在上，走的是 `npc_draws` 给出的 `SurfaceDraw::entity`
升序——与 `ll_render::sprite::DrawOrder` 在同层同脚底纵坐标时的比较键
是同一个。行与列都从注册表现查，加第 10 个种族之后重新跑一遍它会自己
出现在图上。

**不证明**：颜色经过昼夜/天气/迷雾 tint 之后还对不对，与上面两张同一条
局限。

### 自动化的那一半

`crates/ll-game/tests/npc_appearance.rs`：逐条断言本体每个种族/职业都有
自带贴图、52 种组合两两之间至少差整块徽记、同职业跨种族至少差四分之一
张图、mod 自带的种族/职业不改一行引擎代码就能生效。
